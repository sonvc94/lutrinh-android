# 07 — Port to iOS (Swift / SwiftUI)

Goal: a native iOS app with the same features, rules and copy, sharing these docs as the spec.
Suggested floor: iOS 17 (SwiftData, `@Observable`, `PhotosPicker` with `Transferable`).

## Layer by layer

| Concern | Android (this repo) | iOS equivalent | Notes |
| --- | --- | --- | --- |
| Language | Kotlin 2.0 | Swift 5.10+/6 | |
| UI toolkit | Jetpack Compose + Material 3 | SwiftUI | Keep the palette (Theme row below); use native iOS controls rather than imitating Material |
| Screen state | `ViewModel` + `StateFlow`, `Loadable` (Loading/Ready/Missing/Failed) | `@Observable` class per screen + `enum Loadable<T>` | same four states |
| Streams from DB | Room `Flow` | SwiftData `@Query` in views, or `ModelContext` fetch + `NotificationCenter`/observation; GRDB `ValueObservation` if using GRDB | every write must refresh open screens |
| Navigation | Navigation-Compose string routes, one activity | `NavigationStack` with a `Route` enum (`.trip(id)`, `.tripMap(id)`, `.stepEdit(tripId, stepId?)`, …), `.sheet` for forms | picker result: binding or closure instead of `savedStateHandle` |
| Dependency wiring | `AppContainer` (manual) | `AppContainer` struct injected via `.environment` | no DI framework needed |
| Domain models | `data class` | `struct` (Equatable, Hashable, Identifiable) | ids `String` (UUID string), keep the same field names |
| Dates | `LocalDate`, `LocalDateTime` (java.time) | `DateComponents` or own `struct LocalDate {y,m,d}` / `LocalDateTime`; persist as ISO text `yyyy-MM-dd` / `yyyy-MM-dd'T'HH:mm` | do **not** store as `Date` in UTC — a step at 07:00 in Hà Giang must stay 07:00 |

## Things that differ by platform (decide during the port)

* iOS has no system "back" button: the discard-changes dialog fires on the Cancel/back toolbar
  button and on interactive dismiss (`interactiveDismissDisabled` while dirty).
* Delete confirmation on iOS is usually a `confirmationDialog` with a destructive button.
* Date pickers: `DatePicker(.graphical)` in a sheet, forced to Vietnamese (row "Picker language");
  dates are validated on save (R5), as on Android.
* Extend-the-trip question (R17): on a failed save of a step that carries a `StopPrefill`, when
  the only errors are before-start / after-end, show `.alert("Kéo dài chuyến đi?", …)` with
  buttons "Kéo dài và lưu" and `.cancel` "Hủy". Port `TripExtension.widen` 1:1 (pure) and make
  the save one SwiftData `ModelContext` transaction (trip dates + step + photos; with GRDB one
  `db.write`), then store the `added` decision. Do not offer it for manual steps.
* UX flows batch: port `PlaceLabel` (nearest other step — also used by the stop-suggestion card — + `DisplayFormat.km`) and `DisplayFormat.defaultStepTitle` and `TripExtension.caseOf`
  (three alert texts) as pure functions with the Kotlin tests. Trip map carousel: a paging
  `ScrollView` with `.scrollTargetBehavior(.viewAligned)` + `scrollPosition(id:)`; selecting on settle
  = `onChange` of the position. "Vị trí của tôi": `CLLocationManager.requestLocation()` with
  `requestWhenInUseAuthorization` after the rationale; never `Always`. From photos: show a `.sheet`
  intro before the `PHPicker`/document picker and `.confirmationDialog` on back from the review.
* Photo library access (R19): iOS asks once per app; after "Don't Allow" only Settings can change
  it, so the denied note should open `UIApplication.openSettingsURLString` instead of asking
  again. Limited access shows the system "select more photos" alert on first fetch unless
  `PHPhotoLibraryPreventAutomaticLimitedAccessAlert` is set; we set it and offer "Chọn thêm ảnh".
* Large titles exist natively (`navigationBarTitleDisplayMode(.large)`).
* **Fonts.** Android bundles Noto Sans (SIL OFL, Regular/Medium/Bold, `res/font/`, `ui/theme/Type.kt`) for every text style and Barlow Condensed Bold (SIL OFL) for stand-alone numbers with tabular figures (docs/08 §3: the specimen's Noto Sans SC is replaced by Noto Sans, the app has no CJK text); on iOS add the TTFs to the bundle (`UIAppFonts`), use `Font.custom` with the docs/08 type scale (sizes in pt = sp, `relativeTo:` for Dynamic Type) and `.monospacedDigit()` on the numeral style.
* **Trip without a cover photo** (`ui/common/RouteCover.kt`): draw the route with SwiftUI `Canvas`/`Path`; port `RouteFit` (equirectangular fit + graticule step) 1:1 with `RouteFitTest`.
* **Sample photos** (debug only): bundle the same `sample-photos/` JPEGs and README in a debug-only resource; never generate pictures.
