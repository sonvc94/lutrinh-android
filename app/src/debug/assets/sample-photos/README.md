# Sample photos (debug builds only)

Real photos of the sample trips' places for "Tạo dữ liệu mẫu" (debug menu, `data/SampleData.kt`).
They live in the `debug` source set, so release APKs do not contain them. Each is a copy from
Wikimedia Commons, downscaled to 1024 px on the long side, metadata stripped; nothing else was
changed. Keep this table in step with the files: one row per file, its source page, author and
licence. Do not add generated or AI-made pictures here (docs/08-design.md "Imagery").
